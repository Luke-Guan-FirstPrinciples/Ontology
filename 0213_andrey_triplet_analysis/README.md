# Triplet Quality Analysis & LLM Evaluation

Comparative analysis of knowledge-graph triplets from three extraction methods, evaluated for semantic and scientific quality using GPT-5.2.

## Background

We extracted (subject, predicate, object) triplets from arXiv physics papers using three different approaches:

| Source | Method | Scope | Triplets |
|--------|--------|-------|----------|
| **Andrey's LLM pipeline** | GPT-based extraction stored in `graph_rag.graph_triplets_2025_09_09` | 10,448 papers (all domains) | 802,789 total; 100 sampled |
| **konsman/rebel-quantum-mixed** | Fine-tuned REBEL model for quantum physics | 58 quant-ph papers | 174 |
| **Babelscape/rebel-large** | General-purpose REBEL model | 58 quant-ph papers | 60 |

This experiment answers: **which extraction method produces the highest-quality triplets?**

---

## Results Summary

All three sources were evaluated on 20 triplets each by GPT-5.2 using a structured 1-5 scoring rubric.

### Score Comparison (n=20 each)

| Score (1-5) | Andrey LLM | Rebel Large (Babelscape) | Rebel Fine-tuned (Konsman) |
|-------------|:----------:|:------------------------:|:--------------------------:|
| **Semantic** | **3.15** | 2.95 | 2.75 |
| **Scientific** | **3.25** | 2.35 | 2.10 |
| **Specificity** | **2.15** | 2.20 | 1.85 |
| **Overall** | **2.65** | 2.15 | 2.00 |

### Overall Score Distribution

| Overall Rating | Andrey LLM | Rebel Large | Rebel Kons |
|:--------------:|:----------:|:-----------:|:----------:|
| 1 | 0% | 20% | 25% |
| 2 | 40% | 55% | 50% |
| 3 | 55% | 20% | 25% |
| 4 | 5% | 0% | 0% |
| 5 | 0% | 5% | 0% |

### Conclusion

**Andrey LLM > Rebel Large > Rebel Fine-tuned (Konsman)**

- Andrey's LLM pipeline produces the most scientifically accurate and semantically coherent triplets (mean overall 2.65 vs 2.15 / 2.00).
- Rebel Large edges out the fine-tuned Konsman model despite being a general-purpose model, suggesting the fine-tuning may have introduced noise.
- All three sources score low on **specificity** (1.85-2.20), indicating triplets tend to be too generic for a high-quality knowledge graph.

## Scoring Rubric

Each triplet is scored on four dimensions (1-5):

| Dimension | 1 | 3 | 5 |
|-----------|---|---|---|
| **Semantic** | Nonsensical or ungrammatical | Understandable but ambiguous | Perfectly clear, unambiguous |
| **Scientific** | Factually wrong | Plausible but unverifiable | Verified, established fact |
| **Specificity** | Extremely vague (e.g. "results -> show -> data") | Moderately informative | Highly precise, citable relationship |
| **Overall** | Should be discarded | Acceptable but not ideal | Excellent, high-value triplet |

Full prompt is defined in `evaluate_triplets.py` (`SYSTEM_PROMPT`).

## Usage

### 1. Distribution Analysis (Andrey's full DB)

Analyzes all 802,789 triplets from `graph_rag.graph_triplets_2025_09_09` and generates 11 visualizations + frequency CSVs.

```bash
python3 triplet_analysis.py
```

Outputs to `outputs/` — predicate/entity distributions, Zipf plots, heatmaps, etc.

### 2. Download a Random Sample

Pull N random rows from the DB into a CSV for evaluation.

```bash
python3 download_sample.py                    # 100 rows (config.yaml default)
python3 download_sample.py --n_rows 200       # custom sample size
python3 download_sample.py --output data/my_sample.csv
```

### 3. Evaluate Triplets with GPT

Score any triplet CSV using the OpenAI Responses API.

```bash
# Andrey's LLM triplets (default from config.yaml)
python3 evaluate_triplets.py --limit 20

# Konsman fine-tuned REBEL
python3 evaluate_triplets.py \
  --input data/sampled_triplets_rebel_quantph.csv \
  --output data/evaluated_rebel_quantph.csv \
  --limit 20

# Babelscape general REBEL
python3 evaluate_triplets.py \
  --input data/sampled_triplets_rebel_babel_quantph.csv \
  --output data/evaluated_rebel_babel_quantph.csv \
  --limit 20

# Override model
python3 evaluate_triplets.py --model gpt-4.1 --limit 10
```

## Configuration

All settings are in `config.yaml`:

```yaml
sample:
  n_rows: 100                              # rows to sample from DB
  output_file: "data/sampled_triplets.csv"
  table: "graph_rag.graph_triplets_2025_09_09"

columns:
  subject: "subject"                       # column name mapping
  predicate: "predicate"
  object: "object"

evaluation:
  model: "gpt-5.2"                         # gpt-5.2, gpt-4.1, o3, etc.
  reasoning_effort: "medium"               # low / medium / high
  temperature: 0.0                         # ignored for reasoning models
  max_retries: 3
```
